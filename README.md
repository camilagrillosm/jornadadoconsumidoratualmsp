# Jornada Atual da Visita — MSP Estúdios

Painel interativo da apresentação de case *A jornada do consumidor na visita pedagógica ao MSP*.

## Como funciona
1. **Página inicial**: mostra as setas da jornada. Clique em uma etapa para abri-la.
2. **Página da etapa**: tem 5 opções (Sentimentos e Expectativas, O que acontece?, Agentes envolvidos, Importância pedagógica, Pontos limitantes).
3. **Janela de informação**: abre ao clicar em uma opção. Para fechar, use **Voltar**, a tecla Esc ou clique fora da janela.

Cada tela tem o próprio endereço (por exemplo, `#/etapa/chegada/sentimentos`), então dá para mandar o link direto de uma tela específica.

## Como editar os textos
Os textos ficam todos em **`conteudo.js`**. Para preencher um conteúdo, basta colocar o texto entre as crases da opção correspondente.

## Como abrir
Abra o arquivo `index.html` no navegador. Para colocar o site online, ative o GitHub Pages em Settings → Pages → branch → `/ (root)`.
